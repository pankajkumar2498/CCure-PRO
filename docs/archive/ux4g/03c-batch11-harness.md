# Checkpoint 3C — Batch 11 harness

`capture-batch11.mjs` is generated from `capture-batch10.mjs` by
`b11-parts.py` (scratchpad): every edit is an anchored replacement that
asserts its anchor exists exactly once, and the generator verifies at the end
that the batch 10 instrumentation survived — frozen clock, two-byte `\s`
emission, `qsaSelf`, the ARIA-state census, per-header scopes, and the refusal
of every non-GET. Runner: `run-capture11.sh`. Comparator: `diff-batch11.mjs`.

Containers run standalone with `--add-host api:127.0.0.1` (the Docker daemon
was restarted between batches and the compose stack is down; nginx only needs
the upstream name to resolve, and every `/api/` request is intercepted by CDP
before it reaches nginx). The measured frontend is unchanged by this.

exactly two backticks (open and close).

One process failure worth recording: the first attempt to run the eight
regression harnesses in one detached script left two runners racing for the
same Chrome and the same log. The captures it produced were discarded
unread and the set was re-run serially; every figure above comes from the
serial run.
