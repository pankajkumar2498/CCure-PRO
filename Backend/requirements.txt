# ── Optional enhancements ─────────────────────────────────────────────────────
# pyOpenSSL          # deeper TLS inspection in tls_scanner plugin
# python-ldap3       # direct LDAP queries in ldap_probe plugin
impacket==0.13.1   # Windows credentialed scan over SMB / Remote Registry / WMI.
                   # Declared, not optional: the import is reached at scan time
                   # by engines/credentialed/smb_executor.py, which is the
                   # second Windows transport. It also carries the SMB deep
                   # inspection this line previously described as "install
                   # separately", so that arrangement is gone.
                   #
                   # ⚠ 0.13.1, NOT 0.12.0, and the reason is a hard conflict
                   # rather than a preference. 0.12.0 pins `pyOpenSSL==24.0.0`,
                   # which caps `cryptography<43`; sslyze 6.3.1 requires
                   # `cryptography>=43,<47`. The two cannot both be satisfied,
                   # so installing impacket 0.12.0 downgrades cryptography to
                   # 42.0.8 and leaves sslyze's requirement violated — measured
                   # with `pip check`, which reports it in those words. That
                   # matters beyond tidiness: cryptography is also depended on
                   # by paramiko, pysnmpcrypto, pyspnego and requests_ntlm, so
                   # the downgrade reaches SSH, SNMPv3 and WinRM NTLM as well.
                   # 0.13.1 declares `pyOpenSSL` unpinned and resolves against
                   # cryptography 46 with nothing displaced.
                   #
                   # ⚠ It also depends on `pyasn1` WITHOUT an upper bound, and
                   # an unconstrained install can pull pyasn1 6.x — which breaks
                   # pysnmp-lextudio and, with it, SNMP topology discovery. The
                   # failure is not an import error: pyasn1 6 removed
                   # `pyasn1.compat.octets`, and the FDB table silently decodes
                   # to one entry instead of three, so a switch's MAC table
                   # comes back nearly empty and the topology looks sparse
                   # rather than broken. Keep the `pyasn1` pin above ahead of
                   # this line and verify both after any upgrade of either.
                   #
                   # Installing into an existing environment therefore means
                   # naming the constraints so pip cannot resolve around them:
                   #
                   #   pip install "impacket==0.13.1" \
                   #       "pyasn1>=0.4.8,<0.6.0" "cryptography>=43,<47"
                   #
                   # `pip install -r requirements.txt` does this on its own,
                   # because both pins are in this file. The failure mode to
                   # watch for is an environment that was built before this
                   # line existed and never reinstalled: `Backend/.venv` was in
                   # exactly that state until 2 Sep 2026 — 44 of 45 declared
                   # packages present, impacket the only one missing — so the
                   # SMB transport raised SMBConfigurationError in the worker
                   # while passing in a developer's global interpreter that had
                   # been given impacket by hand.
